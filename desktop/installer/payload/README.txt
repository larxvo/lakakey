Lakakey 0.10.1 — Windows Desktop

Install: open LakakeyDesktopSetup.exe.
Launch: Start Menu > Lakakey.
Close: the window hides to the system tray.
Tray: right-click for actions; Alt+Z switches the selected state when enabled.
Remove: Windows Settings > Installed apps > Lakakey.

The text-input integration remains under development. The installer does not install a keyboard driver.
