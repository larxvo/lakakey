Lakakey 0.11.0 — Windows Desktop development build
Created by Larx Vo · https://vovinhlac.com

Install: launch LakakeyDesktopSetup.exe.
Launch: Start Menu > Lakakey.
Close: hides Settings to the system tray.
Tray: single click changes desktop VN/EN preference; double click opens Settings.
Uninstall: Windows Settings > Apps > Installed apps > Lakakey.

The current installer does not register an operating-system input service.
Native input integration is in development and is assessed separately.
No account, advertising, telemetry or typed-text logging.
