This installer adds a Windows-native Settings panel, local preferences,
Start Menu entry and system-tray utility. It is NOT a Vietnamese system input
method and does not register a TSF input processor. Please keep using your
existing input method for actual typing.

Install: run LakakeyDesktopSetup.exe. Close the old app before updating.
Uninstall: Windows Settings > Installed apps > Lakakey Desktop Beta.

Installer is unsigned, and has not been verified on physical Windows hardware.
No accounts, network calls, keyboard interception, or forced watermarks.
