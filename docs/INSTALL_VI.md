# Hướng dẫn cài Lakakey Windows (bản PREVIEW)

> **Lưu ý:** Đây là phần mềm xem trước Settings. **CHƯA gõ được tiếng Việt toàn hệ thống**. Tiếp tục sử dụng UniKey để gõ tiếng Việt.

## Cách tải file EXE từ GitHub

1. Mở trang [Lakakey Releases](https://github.com/larxvo/lakakey/releases).
2. Mở bản **v0.8.0-preview (Pre-release)** và chọn **Assets → LakakeyPreviewSetup.exe**. Nếu chưa có bản phát hành, mở [Actions](https://github.com/larxvo/lakakey/actions/workflows/windows-preview.yml), chọn workflow đã chạy thành công và tải artifact **LakakeyPreview-Windows-x64**.
3. Nhấp đúp file `LakakeyPreviewSetup.exe` để mở chương trình cài đặt. Đọc thông báo và chọn Yes nếu đồng ý cài bản xem trước.
4. Sau khi cài, cửa sổ Lakakey Preview sẽ mở. Các nút VN/EN chỉ thay đổi giao diện demo; chúng **không** thiết lập bộ gõ Windows.

## Gỡ cài đặt

Windows Settings → Apps → Installed apps → Lakakey Desktop Preview → Uninstall. Bộ cài dành cho mỗi tài khoản (per-user) và không đụng vào UniKey.

## Nếu Windows cảnh báo

Đây là ứng dụng thử nghiệm chưa ký chứng thư số. Hãy chỉ chạy bản tải từ repository chính thức và xác minh tệp. Không nên bỏ qua các cảnh báo bảo mật nếu bạn không chắc nguồn gốc. Không tải các gói từ trang bên thứ ba.

## Các hệ điều hành khác

macOS và Linux hiện chưa có bản cài. Các bộ tích hợp InputMethodKit, IBus và Fcitx5 vẫn trong kế hoạch phát triển.
