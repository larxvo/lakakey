# Lakakey Desktop Preview 0.7.1 — Packaging

## What the release package does

Contains a **Windows x64 GitHub Actions release pipeline** and Inno Setup project that compile the Windows Settings and mascot programs and create a one-click `.exe` installer named `LakakeyPreviewSetup-v0.7.1-win-x64.exe` **on a Windows build runner**. The workflow runs both engine tests and checks compiled PE headers. It does not exercise actual typing in Chrome/Word or mascot rendering.

## Important limitations

- No actual installer or Windows binary is included in this repository ZIP; it must be generated by running the Windows CI workflow or by compiling on Windows.
- The current Settings toggles only change UI state, **not the keyboard language input processor**.
- The TSF experiment is excluded by default; do not distribute it as a working input method.
- Windows build, setup, and runtime behavior are still unverified until the workflow and application smoke tests run on Windows.
- The installer is unsigned; user may see SmartScreen warning, never bypass a warning for a binary from an untrusted source.

## Build an installer on a Windows 10/11 machine with development tools

1. Install Visual Studio 2022 Build Tools with Desktop development with C++ and CMake, plus Inno Setup 6.
2. Open Developer PowerShell in repository root and run:

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DLAKAKEY_BUILD_EXPERIMENTAL_TSF=OFF
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
New-Item -ItemType Directory -Force dist/assets | Out-Null
Copy-Item build/Release/LakakeySettings.exe dist/
Copy-Item build/Release/LakakeyMascot.exe dist/
Copy-Item platform/windows/mascot/assets/* dist/assets/
& 'C:/Program Files (x86)/Inno Setup 6/ISCC.exe' installer/LakakeyPreview.iss
```

The generated installer, if build succeeds, is in `installer/output/`.
