# Lakakey v0.8.0 PREVIEW — Windows x64

**Status: Windows desktop Settings demonstration, NOT a Vietnamese input method.**

Included: Win32 Settings preview, theme selector, VN/EN demo switch, optional mascot mode (Full/Minimal/Off), Larx Vo author link, per-user EXE installer with uninstaller, Windows Go build and CI workflow, portable C++17 Telex/VNI core source.

Missing: working system-wide Windows TSF IME, normal Vietnamese typing in Chrome/Word/Edge/VS Code, cross-platform installers, complete rigged 3D animation system, signed binary, verified Windows compatibility.

**Download:** GitHub Releases → v0.8.0-preview → Assets → LakakeyPreviewSetup.exe (after a successful Actions build).
