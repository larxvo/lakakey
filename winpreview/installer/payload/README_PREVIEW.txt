LAKAKEY v0.8 — INSTALLABLE WINDOWS PREVIEW
Author: Larx Vo | https://vovinhlac.com | Copyright (c) 2026

QUAN TRONG — VUI LONG DOC TRUOC KHI CAI:
Ban v0.8 la ban xem truoc giao dien Lakakey. NO KHONG PHAI BO GO TIENG VIET, khong the go tieng Viet trong Word, Chrome, Notepad. Vui long tiep tuc dung UniKey cho den khi Lakakey TSF IME duoc hoan thanh va kiem thu tren Windows.

CACH CAI:
1. Mo file LakakeyPreviewSetup.exe bang cach nhap dup.
2. Thong bao canh bao la ban preview se xuat hien. Chon Yes neu muon cai.
3. Cua so Settings preview se mo ra sau khi cai.
4. De go bo, mo Windows Settings > Apps > Installed apps > Lakakey Desktop Preview > Uninstall.

NHUNG GI BAN NHAN DUOC:
- File Windows .exe thuc su (PE32+ x64) duoc build bang Go standard library.
- Cua so Settings native voi nut chuyen VN/EN (chi la preview), lua chon mascot Full/Minimal/Off, mau theme, hinh mascot va link tac gia.
- Ma nguon Go cua ban preview + ma nguon C++ va UI/mascot TSF tu cac phien ban truoc.
- Source/README va GitHub Actions de build lai tren Windows.

TRANG THAI KIEM THU:
- Da cross-compile ca 2 EXE tu Linux va xac minh dinh dang PE32+ (x64).
- Chua chay thu tren may Windows thuc, chua duoc ky so.
- TSF goc chua hoat dong, chua dat chat luong thay the UniKey.
