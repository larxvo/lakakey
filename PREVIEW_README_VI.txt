Lakakey Desktop Preview v0.7.1 — WINDOWS x64

IMPORTANT: THIS IS NOT YET A VIETNAMESE INPUT METHOD.
This release installs Lakakey Settings and Mascot only.
VN/EN controls are only a visual preview and WILL NOT change typing in other apps.
Do NOT uninstall UniKey yet.

How to install on Windows:
 1. Download LakakeyPreviewSetup-v0.7.1-win-x64.exe from a successful Windows release build.
 2. Double-click it and choose Install.
 3. Open Lakakey Preview from the Start menu.
 4. Use Apps -> Installed apps to uninstall.

The .exe is unsigned until code signing certificates are configured.
This preview requires Windows 10/11 x64 and does NOT register experimental TSF.
For an actual UniKey replacement, Lakakey still needs TSF composition and
Windows application compatibility testing.
