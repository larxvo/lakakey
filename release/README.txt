This is the Linux x86_64 Lakakey CORE LAB, not a system-wide Vietnamese input method.
It can demonstrate text conversion through a terminal and should not replace UniKey.
Use source package for rebuilding on Windows, macOS or Linux.

Example:
  printf 'tieengs\nnguowif\n' | ./lakakey_lab
  printf 'a61\n' | ./lakakey_lab --vni
